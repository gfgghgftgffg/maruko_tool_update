# 兼容范围

当前已验证 Windows x64 的 8bit。兼容性测试使用 CRF 24、preset 8、ref 4、B 帧 3、umh、scenecut 60、deblock 1:1、qcomp 0.5、psy-rd 0.3:0、AQ 2/0.8；subme 10、me_range 24、lookahead 60 等设置保持。设置一致不保证像素、码流、体积、画质或速度一致。

已验证中文 MP4 输入、H.264 yuv420p 输出、小丸格式的缩放参数、VSFilter64 字幕烧录、外部 FFmpeg 复制 AAC 和原 MP4Box 合并。管理脚本使用自动生成的素材执行验证，并输出字幕检查截图。

覆盖包同时提供独立 FFmpeg 9.0.2。验证直接调用包内 ffmpeg.exe 检查版本、生成测试视频、复制 AAC、转码为 48 kHz 双声道 AAC，以及解码 x264 输出；不借用开发包中的 ffmpeg.exe 完成这些检查。

| 项目 | 状态 |
|---|---|
| UI 启动、进度、取消、批量 | 未验证 |
| 全片同步、复杂素材、多种输入格式 | 未系统验证 |
| 小丸其他 FFmpeg 页面、旧参数和进度解析 | 未全面验证 |

| 32 位、x265 | 未实现 |
| 内部音频 | 关闭，使用原外部音频工作流 |

修复缺口后同步文档、lock 能力和验证步骤。不得静默忽略失败或改变用户参数。release manifest 必须明确未验证内容。
